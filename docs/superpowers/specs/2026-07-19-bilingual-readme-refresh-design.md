# Codex Mochi 双语 README 更新设计

## 目标

把仓库首页更新为与当前版本一致的完整双语说明，让中文和英文用户都能快速理解 Codex Mochi 是什么、如何安装、显示的数据来自哪里，以及会员倍数与本机 Token 的准确边界。

## 结构

- 保留单个 `README.md`，顶部提供中文与 English 锚点导航。
- 中文完整版在前，英文完整版在后，两部分使用相同的信息层级。
- 顶部保留项目名、CI、系统版本与许可证徽章，并用一句话说明“菜单栏里的 Codex 额度糯米猫”。
- 依次组织为：项目简介、核心亮点、界面信息、安装与使用、数据口径与隐私、会员识别边界、开发、当前边界、灵感与许可证。
- 截图只有在仓库内存在与当前版本一致的正式图片时才加入；本次不发布过时截图，也不放无效占位链接。

## 内容要求

- 覆盖菜单栏剩余额度、紧凑弹窗、互动糯米猫、8 套柔色主题、主题联动进度条、Plus / Pro 5x / Pro 20x 展示、重置卡、今日 Mac 原始 Token、最近 15 分钟速率、爆猫粮和火花动效。
- 明确底栏顺序为 `Star → 刷新 → 退出`，Star 按钮打开项目 GitHub 地址。
- 安装步骤同时给出构建命令、打开方式、移动到“应用程序”文件夹以及 macOS 临时签名提示。
- 明确额度来自 Codex 已有登录信息，本机 Token 来自本地会话日志；两者不是同一种计量。
- 明确 Pro 5x / Pro 20x 不能总是由接口自动识别，因此允许用户在本机手动选择展示。
- 保留“本地优先、无遥测、不上传提示词或聊天历史、不修改额度或重置卡”的隐私承诺。
- 中英文内容语义一致，但不做逐句生硬直译；英文使用自然的开源项目表达。

## 验收标准

- README 中英文两部分完整、可通过顶部锚点互相跳转。
- 所有功能、尺寸、URL、命令、系统要求和隐私描述均能从当前代码或构建脚本核实。
- 不包含失效图片、虚构安装包、未经实现的能力或对官方额度 Token 的误导。
- Markdown 链接、代码块和标题层级正常，`git diff --check` 通过。
- 修改以 `Exusty` 作者身份提交并推送当前分支。
