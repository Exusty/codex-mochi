# CodexMochi 今日 Mac Token 与可爱速率设计

## 目标

在现有周额度展示之外，增加本机当天实际处理的原始 Token 总量和短时 Token 速度。数据仅从 `~/.codex/sessions` 的 Codex 会话日志读取，不上传、不修改日志，也不把原始 Token 描述成官方额度 Token。

## 数据口径

- “今日”使用用户当前日历和时区，从本地 00:00 开始。
- 解析 `token_count.info.total_token_usage`，按每个会话累计值的正向增量统计，避免重复累计事件。
- 分类保留输入、缓存输入、输出和推理输出；主数字使用 `total_tokens`。
- “最近速度”采用最近 15 分钟的 Token 增量，折算成 Token/小时。
- 只统计当前 Mac 可见的持久化 Codex 会话；临时会话、其他设备和不可见云端任务不在统计范围内。

## 速度状态

| 最近 Token/小时 | 状态 | 文案 |
|---:|---|---|
| 无样本 | 观察中 | 糯米猫在找今天的饭碗 |
| 0 | 休息 | 糯米猫舔舔爪，碗里很安静 |
| < 10 万 | 轻尝 | 糯米猫小口啃饼 |
| < 100 万 | 进餐 | 糯米猫认真嚼口粮 |
| < 500 万 | 猛吃 | 糯米猫抱着饭碗猛吃 |
| >= 500 万 | 起飞 | 糯米猫端着饭碗起飞了 |

## 界面

新增淡蓝色 Token 卡片，置于周额度卡片与现有百分比节奏卡片之间：

```text
┌ 今日 Mac 口粮                 原始 Token ┐
│ 2,890 万            最近 15 分钟          │
│ 输入 / 缓存 / 输出   1,584 万 / 时         │
│ 糯米猫端着饭碗起飞了                    │
└───────────────────────────────────────┘
```

周额度速度继续显示 `% / 时`；Token 卡显示 `Token / 时`，避免把两种速率混为一谈。Token 速度只影响 Token 卡片中的趣味文案，菜单栏猫的最终动效取周额度紧张程度和 Token 活跃程度中的较高者。

## 错误处理与性能

- 日志目录不存在、没有权限或没有当日样本时显示“等待本机记录”，不显示虚构数字。
- 跳过损坏的 JSONL 行和缺字段事件，其余文件继续统计。
- 每分钟随额度刷新重新扫描当天目录；当前日志规模较小，首版优先保证简单可靠。

## 测试

- 同一会话累计 Token 正向增长正确计入，重复累计值不重复计算。
- 会话累计值重置时仅计入新的正值，不产生负数。
- 跨日事件只计入本地当天。
- 最近 15 分钟速率和五档可爱状态边界正确。
- 损坏行、缺失目录和空数据返回诚实的空状态。
