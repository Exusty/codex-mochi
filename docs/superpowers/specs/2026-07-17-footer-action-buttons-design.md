# 底栏操作按钮框设计

## 目标

让弹窗右下角的“刷新”和“退出”一眼可识别为可点击操作，同时保持现有紧凑尺寸、布局、文案和所有其他元素不变。

## 设计

- 两个操作继续位于底栏右侧，顺序保持“刷新、退出”。
- 每个操作使用独立的 `24pt` 高柔色圆角框，圆角 `7pt`，水平内边距 `8pt`。
- “刷新”沿用当前主题强调色，使用低透明度底色与细边线；“退出”使用现有次要文字色的低透明度底色与细边线。
- 保留刷新图标、刷新中状态、禁用行为和退出文案。
- 按下时只略微加深底色和边线，不新增持续动画。
- 底栏高度继续为 `42pt`，弹窗继续为 `348 × 404`，不改状态点、更新时间、卡片和其他交互。

## 验收标准

- “刷新”和“退出”各自具有清晰、独立的小按钮框。
- 按钮在普通、按下和刷新禁用状态下仍可辨识。
- 底栏不增高，状态文字不会被按钮覆盖。
- 完整测试、Release 构建、签名、配置和差异检查通过。
- 新版替换当前运行应用；不提交、不推送。
