# 弹窗空白压缩设计

## 目标

移除 Codex Mochi 三张信息卡与底栏之间不承载信息的大块空白，让弹窗高度贴合现有内容，同时保持宽度、信息、交互和视觉风格不变。

## 设计

- 弹窗宽度继续为 `348pt`。
- 弹窗高度由 `500pt` 调整为 `404pt`。
- 删除卡片区与底栏之间会自动扩张的 `Spacer`，改为固定 `6pt` 间距。
- `PopoverView` 根视图和 `NSPopover.contentSize` 使用相同的 `348 × 404` 尺寸，避免 AppKit 容器再次产生额外空间。
- 头部、三张卡片、会员与主题菜单、小猫互动、猫粮动画、状态、刷新和退出按钮全部保持不变。
- 不修改额度、Token、会员识别、刷新周期或任何数据逻辑。

## 验收标准

- 本机弹窗中，今日 Mac 口粮卡下方只保留约 `6pt` 间距后进入底栏。
- 三张卡片与底栏均完整显示，没有裁切或重叠。
- 源码中不再存在用于撑开主内容与底栏的 `Spacer(minLength: 6)`。
- `PopoverView` 和 `NSPopover` 的尺寸均为 `348 × 404`。
- 完整测试、应用构建、签名、配置和差异检查通过。
- 新版替换当前运行的本机应用；不提交、不推送。
