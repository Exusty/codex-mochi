# CodexMochi 互动猫、柔色主题与重置卡设计

## 目标

让弹窗顶部的糯米猫可以点击互动，允许用户选择并持久化柔色主题；保留主周额度卡，将次窗口替换为可用重置卡展示；在“今日 Mac 口粮”中加入会随 Token 速度变化的猫粮碗动画。

## 信息结构

弹窗从上到下保持以下顺序：

1. 可互动糯米猫、周额度标题、柔色主题按钮。
2. “本周额度 · 主窗口”卡片。
3. “重置卡”卡片，替代原“本周额度 · 次窗口”。
4. “今日 Mac 口粮”卡片，右侧包含猫粮碗动画。
5. 现有本周百分比节奏卡片、状态与操作按钮。

## 重置卡数据

- 从现有 `/backend-api/wham/usage` 响应的 `rate_limit_reset_credits` 读取：
  - `available_count`：储备重置卡数量。
  - `applicable_available_count`：此刻可实际使用的数量。
- 当前真实响应为储备 3 张、当前可使用 0 张。
- 卡片主数字显示储备数量，副文案显示当前可使用数量。
- 缺字段时显示“暂未读到重置卡”，绝不把缺失数据当作 0。
- 首版只展示，不提供兑换按钮，不修改账户。

## 猫咪互动

- 整个猫脸是无边框点击区域，保留键盘可访问性和辅助功能标签。
- 每次点击按顺序切换：爱心眼、星星眼、害羞脸、眯眼笑、吐舌头。
- 点击时猫脸轻弹，并显示与表情匹配的短粒子；1.5 秒后恢复到速度驱动的常态表情。
- 连续点击会立即切到下一种表情，旧的恢复任务不得提前覆盖新表情。
- 错误状态优先于互动表情，避免隐藏额度读取失败。

## 柔色主题

主题按钮位于猫旁边，使用小调色盘图标。点击打开原生菜单，提供：

- 薄荷
- 天空蓝
- 薰衣草
- 樱花粉
- 蜜桃
- 奶油黄
- 燕麦
- 雾灰

选择后立即更新猫、Token 卡、重置卡、按钮和装饰色，并通过 `UserDefaults` 保存。额度健康、警告、危险的绿/黄/红语义颜色不随主题改变。

## 猫粮碗动画

猫粮碗使用 SwiftUI 矢量形状绘制，不增加外部图片资源。它包含柔色碗体、猫爪标记、环形猫粮颗粒和少量速度粒子。

| Token 速度状态 | 动画 |
|---|---|
| 观察中/休息 | 静止，仅轻微呼吸 |
| 小口啃饼 | 左右轻摆 |
| 认真嚼粮 | 缓慢旋转 |
| 抱碗猛吃 | 快速旋转并出现碎屑 |
| 饭碗起飞 | 高速旋转、风线和星星 |

动画速度直接复用 `TokenSpeedMood`，不会根据额度百分比伪造 Token 速度。开启“减少动态效果”时停止连续旋转，只保留静态状态差异。

## 组件边界

- `QuotaParser`：解析重置卡数量。
- `QuotaSnapshot`：携带储备与当前适用数量。
- `MochiTheme`：主题标识、名称和颜色定义。
- `CatReaction`：点击顺序、显示文案和恢复规则。
- `FoodBowlMotion`：将 Token 速度状态映射为动画级别。
- `PopoverView`：组合布局，不承担网络或解析逻辑。
