# GitHub Star 按钮设计

## 目标

在弹窗底栏的“刷新”按钮前增加一个容易识别的 GitHub Star 入口，引导用户打开 Codex Mochi 项目页面，同时保持现有紧凑布局和其他行为不变。

## 设计

- 按钮顺序调整为 `Star → 刷新 → 退出`。
- Star 按钮使用 `star.fill` 图标和 `Star` 文案。
- 沿用现有 `FooterActionButtonStyle` 的 `24pt` 高度、`7pt` 圆角与 `8pt` 水平内边距。
- 使用柔和奶油金强调色，与现有柔色主题协调，但不随主题变化，以维持 GitHub Star 入口的稳定识别。
- 点击后通过系统默认浏览器打开 `https://github.com/Exusty/codex-mochi`。
- URL 无效或系统无法打开时不崩溃，不改变应用内状态。
- 保持底栏 `42pt`、弹窗 `348 × 404`，不修改状态文字、刷新、退出及其他界面元素。

## 验收标准

- Star 按钮显示在刷新按钮之前，外观与现有小按钮一致。
- 点击目标精确为 `https://github.com/Exusty/codex-mochi`。
- 刷新和退出功能保持原样。
- 34 项现有测试继续通过，并新增项目链接测试。
- Release 构建、签名、配置和差异检查通过。
- 新版替换当前运行的本机应用；不自动提交或推送。
