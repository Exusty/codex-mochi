# 爆猫粮动效设计

## 目标

替换“猫粮碗整体旋转”的表现。饭碗保持稳定，猫粮像爆米花一样向外喷出并渐隐；Token 消耗越快，喷出的猫粮越密集，快速状态加入火花，非常快时火花与猫粮向四周直溅。

## 速度分级

- `learning` / `resting`：饭碗静止，不生成粒子。
- `nibbling`：每轮偶尔生成 1 颗猫粮，短距离向上冒出并渐隐。
- `munching`：每轮生成 2–3 颗猫粮，沿不同角度向上喷出并渐隐。
- `gobbling`：生成更密集的猫粮，并加入短火花。
- `flying`：猫粮与长火花高速向四周直溅，粒子离开饭碗后渐隐。

## 实现边界

- 使用 SwiftUI `TimelineView` 和确定性粒子槽位实现，不在每一帧重新随机生成，避免闪烁和轨迹跳变。
- 核心层把 `TokenSpeedMood` 映射为可测试的爆发样式，包括猫粮数量、火花数量、周期和扩散强度。
- 界面层仅负责根据样式计算粒子的位置、缩放和透明度。
- 饭碗本体不旋转、不抖动；主题颜色继续用于饭碗和火花，猫粮保持暖棕色。
- 开启 macOS“减少动态效果”时不播放粒子位移动画，只保留静态饭碗。

## 验收标准

- 五档速度映射有自动化测试。
- `gobbling` 明确出现短火花，`flying` 的粒子数量、扩散距离和火花长度明显更高。
- 原有额度、重置卡、主题和点击小猫功能不受影响。
- 完整测试、Release 构建、签名和 `Info.plist` 校验通过，并替换当前本机菜单栏进程。
